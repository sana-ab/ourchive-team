# 🏆 Ourchive - Emotional Memory Archive

**Calgary Hacks 2026 - Track 2: Preserve Today for Tomorrow**

> An emotion-triggered memory capture app that creates living archives accessible by location and time.

---

## 🎯 The Problem

We take 3.2 trillion photos yearly, but we've lost the **emotional context**. Traditional archives preserve facts, not feelings.

## 💡 Our Solution

**Ourchive** uses biometric triggers to automatically prompt memory capture during emotionally significant moments, creating a searchable archive of human experience.

### Key Features

- 🫀 **Biometric-triggered capture** - ML emotion detection from heart rate
- 🗺️ **3D Globe visualization** - Explore memories by location
- 🔒 **Privacy controls** - Public, Friends, or Private
- 📊 **Emotional heatmaps** - Collective emotional mapping
- 🏛️ **Living archives** - Emotional time travel for future generations

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm

### Setup

**1. Clone the repo**
```bash
git clone https://github.com/YOUR-USERNAME/ourchive-team.git
cd ourchive-team
```

**2. Install Frontend**
```bash
cd frontend
npm install
npm start
```
Opens at http://localhost:3000

**3. Install Backend** (in new terminal)
```bash
cd backend
npm install
npm run dev
```
Runs at http://localhost:3001
